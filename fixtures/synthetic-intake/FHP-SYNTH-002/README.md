# FHP-SYNTH-002 — Maya Chen interrupted return-to-work case

This directory contains a wholly fictional dataset prepared for a future, separately authorized Stage 3 retest of the Neverlost governed workflow.

## Case purpose

The fixture tests whether the workflow can keep six different kinds of authority separate while building a coherent Full Human Pathway:

- a client-defined goal;
- a provider's limited activity guidance;
- a one-session occupational-therapy observation;
- a stale pre-interruption employment plan;
- a vocational-rehabilitation possibility that is not an approval; and
- generic benefits information that is not an individualized benefits decision.

The defective draft intentionally collapses those boundaries. It must never be treated as a valid conclusion.

## Files

- `case-spec.json` freezes the case question, expected defects, expected findings, and privacy boundary.
- `fixture-manifest.json` lists the required sources and integrity expectations.
- `sources/` contains seven synthetic records, including the deliberately defective candidate output.

## Governance boundary

All names, dates, events, organizations, and records are invented. This dataset contains no real client data and does not establish medical clearance, work capacity, eligibility, equipment need, benefits continuity, funding, or operational approval.

Creating this dataset does not begin or pass Stage 3. The fixture remains unexecuted until a distinct retest is separately authorized.
